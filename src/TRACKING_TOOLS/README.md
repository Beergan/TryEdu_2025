## 🎯 WORKFLOW TRACKING

### 📅 **Daily Routine (9:00 AM - 5:00 PM)**

#### Morning (9:00 AM):
1. **Standup Meeting** (15 min)
   - What did I do yesterday?
   - What will I do today?
   - Any blockers?
   
2. **Update Tracking** (5 min)
   - [ ] Open `01_PROJECT_TRACKING_SPREADSHEET.md`
   - [ ] Log yesterday's completed tasks
   - [ ] Update task status
   - [ ] Check risk register for new issues

#### During Day:
3. **Work on Tasks**
   - Reference Gantt chart for priorities
   - Log hours spent
   - Note any blockers immediately

#### Evening (5:00 PM):
4. **EOD Updates** (10 min)
   - [ ] Update `03_BURNDOWN_CHART_TEMPLATE.md`
   - [ ] Calculate today's velocity
   - [ ] Update burndown chart
   - [ ] Log actual hours worked
   - [ ] Update risks if any

## 📊 QUICK REFERENCE GUIDES

### ✅ How to Update Task Status:
```
1. Open: 01_PROJECT_TRACKING_SPREADSHEET.md
2. Find your task in Task Tracking sheet
3. Update Status column:
   - Not Started → In Progress
   - In Progress → Completed
4. Update Progress % (0-100%)
5. Log Actual Hours
6. Add Notes if any blockers
```

### 📉 How to Update Burndown:
```
1. Open: 03_BURNDOWN_CHART_TEMPLATE.md
2. Go to Daily Burndown table
3. Find today's row
4. Count tasks completed today
5. Calculate story points (tasks × 2)
6. Update "Tasks Remaining" column
7. Update "Actual Burndown" column
8. Calculate variance from ideal
```

### 🚨 How to Log a New Risk:
```
1. Open: 04_RISK_TRACKING_CHECKLIST.md
2. Copy risk template
3. Assign new Risk ID (R0XX)
4. Fill in all fields:
   - Category
   - Probability (1-3)
   - Impact (1-3)
   - Risk Score
   - Description
   - Mitigation
   - Contingency
5. Assign owner
6. Set review dates
7. Add to risk dashboard count
```

### 📅 How to Check Timeline:
```
1. Open: 02_GANTT_CHART_TIMELINE.md
2. Find current week section
3. Check critical path tasks
4. Verify dependencies
5. Update completed tasks (▢ → █)
6. Adjust if behind schedule
```

## 🚨 ALERT THRESHOLDS

### 🟢 Green (All Good):
- On or ahead of schedule
- Velocity ≥ 10 points/day
- No critical bugs
- High risks ≤ 2

### 🟡 Yellow (Watch Closely):
- 1-2 days behind
- Velocity 7-9 points/day
- Critical bugs 1-2
- High risks 3-4

### 🔴 Red (Immediate Action):
- 3+ days behind
- Velocity < 7 points/day
- Critical bugs ≥ 3
- High risks ≥ 5

**Actions when Red:**
1. Escalate to Phong/Nguyên immediately
2. Emergency team meeting
3. Review scope reduction
4. Add resources if possible
5. Adjust timeline
