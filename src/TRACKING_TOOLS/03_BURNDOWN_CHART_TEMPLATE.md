## 📊 EXCEL/SHEETS FORMULAS

### For Google Sheets / Excel:

**Cell A2 (Date):**
```
=DATE(2025,11,27)+ROW()-2
```

**Cell B2 (Day):**
```
=ROW()-1
```

**Cell C2 (Tasks Remaining):**
```
=165-SUM($H$2:H2)
```
where H is "Tasks Completed Today"

**Cell D2 (Story Points Remaining):**
```
=C2*2
```
(assuming 2 points per task)

**Cell E2 (Ideal Burndown):**
```
=330-(10*B2)
```

**Cell F2 (Actual Burndown):**
```
=D2
```

**Cell G2 (Variance):**
```
=F2-E2
```

**Cell H2 (Velocity):**
```
=SUM(tasks_completed_today)*2
```

### Every Day at EOD (5:00 PM):
1. Count tasks completed today
2. Update "Tasks Remaining"
3. Calculate story points
4. Update actual burndown line
5. Calculate variance
6. Note if behind/ahead of schedule
7. Identify blockers

### Red Flags:
- **3 days behind schedule**: Immediate action required
- **Velocity < 7 points/day**: Review workload
- **Zero progress for 2 days**: Escalate to PM
