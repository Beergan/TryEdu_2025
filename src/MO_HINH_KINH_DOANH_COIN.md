## 📊 KEY METRICS

### **Unit Economics:**
```
Average Revenue Per User (ARPU):
- Tháng 1-6:    60,000 VND/tháng (3 bài × 20K)
- Tháng 7-12:   88,000 VND/tháng (4 bài × 22K)
- Năm 2+:      125,000 VND/tháng (5 bài × 25K)

Customer Acquisition Cost (CAC):
- Marketing cost / New users
- Target: < 200,000 VND/user

Lifetime Value (LTV):
- ARPU × Average lifetime (24 tháng)
- Target: > 2,000,000 VND/user

LTV/CAC Ratio:
- Target: > 3x (healthy)
- Expected: 10x (excellent)
```
